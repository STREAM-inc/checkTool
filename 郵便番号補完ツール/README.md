# 郵便番号補完ツール

住所から、空欄の郵便番号を日本郵便のデータ（`data/utf_ken_all.csv`）で補完します。
目検ツールもこのフォルダのデータを使います。

## インストール

[ルートの README](../README.md) のとおり `checkTool` を取得すれば使えます（郵便番号データは同梱）。

## 設定

設定ファイルはありません。

CSV に必要な列：`住所`・`郵便番号`（`都道府県` があれば優先して使う）。既に値がある郵便番号は上書きしません。

郵便番号データの更新：[日本郵便のダウンロードページ](https://www.post.japanpost.jp/zipcode/dl/utf-zip.html) の「住所の郵便番号（1レコード1行、UTF-8形式）」を展開して `data/utf_ken_all.csv` を置き換える。

## 起動

1. `input` フォルダに CSV を置く
2. `郵便番号補完.bat` をダブルクリック
3. `output` フォルダに `元のファイル名_郵便番号補完済.csv` が出る（元の CSV は `input_done` に移動）
