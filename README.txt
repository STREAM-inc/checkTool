===========================================================
 目検ツール
===========================================================

Backlogの課題の「リスト詳細」を1行ずつ確認しながら、納品リストを
自動修正・チェックするためのツールです。ブラウザで操作します。


■ 起動

  目検ツール.bat をダブルクリック → ブラウザで http://localhost:8765 が開く
  （黒い画面を閉じると終了。初回だけ郵便番号データ等の読み込みに数秒かかります）


■ 使い方

  1. 右上に自分の名前を入れる（チェックした人として記録されます）
  2. 左の「＋ 手動で追加」を押すと小さいウィンドウが開くので、
     課題番号（例: 15096 / STREAMREQ-15096）かURLを入れて「取得」（Enterでも可）
       → ウィンドウが閉じて、リスト詳細・エリア・添付ファイル・作業者の実行サマリが出ます
     （左のタスクのタブをクリックしても課題が開きます）
  3. 添付の「この添付で目検」を押す
     （または「＋ 手動で追加」のウィンドウで CSV をドラッグ&ドロップ / input フォルダのファイルを「処理」）
       → 自動修正したCSVと、チェックリストができます
  4. チェックリストを上から1行ずつ確認して「担当」にチェック
     オーナーは「オーナー」列にチェック（誰がいつ付けたか残ります）
  5. 必要なら「Backlogにチェック結果を投稿」で課題にコメント
     （投稿前に内容の確認・編集画面が出ます）

  ファイル名に【STREAMREQ-xxxxx】が入っていれば、課題は自動で紐づきます。


■ タスクのタブ（画面の左端）

  課題を「取得」したり、課題付きのCSVを処理すると、その課題のタブが自動で追加されます。
  ・チェックボックス … 完了にする（タブに取り消し線、上に「x/y 完了」）
  ・名前 … ダブルクリック または ✎ で変更（Enterで確定・Escで取り消し）。課題を開き直しても名前は変わりません
  ・タブをクリック … その課題を開く
  ・メモ … 選んだタブの下の欄に覚えておくことを書く（自動保存）
  ・✕ … タブを削除（Backlogの課題やチェック結果は消えません）
  ・まとめて追加 … 「18161 18163 18164」のような番号、または今日の課題一覧（1行に「STREAMREQ-xxxxx 件名…」）を
                   貼り付けて「まとめて追加」（Ctrl+Enterでも可）。一覧の件名がそのままタブ名になり、
                   番号だけのものはBacklogから件名を取得。同じ課題は1回だけ・追加済みの課題はそのまま
  ・全部クリア … タブを全部消す（直前の状態は tasks.json.bak に残る）
  ・「＋ 手動で追加」… ①課題を開く・②ファイルを入れる・Backlogに無いタスクの追加 のウィンドウを開く
                       （✕・Esc・外側クリックで閉じる）
  保存先は 設定.txt の TASKS_FILE（初期値: このフォルダの tasks.json）。


■ 子課題（目検タスク・検品の担当）

  課題を開くと「子課題（目検・検品）」に子課題の一覧が出ます。
  「目検タスクを追加」… 種別「その他」、件名「目検　{親課題名}」、担当＝自分（APIキーの持ち主）で子課題を作成
                        （目検タスクが既にあるときはリンクだけ表示して作らない）
  各子課題の右の「自分の担当にする」… その子課題の担当者を自分に変更（すでに自分なら「自分の担当」と表示）
  子課題の行をクリック … その下に詳細（本文）を表示。下の「▲ 閉じる」か行をもう一度クリックで閉じる
  ボタンは押すと確認が出て、OKでBacklogに反映されます。


■ 自動修正の内容

  名称        先頭の「=」を削除（Excelで数式扱いになるため）
              先頭が「+」「@」の名称はチェックリストに目視対象として表示
  資本金      「1,000万円」「1億2,000万円」「10,000千円」→ 10000000（円の整数）
              「非公開」「資本金なし（社会福祉法人）」等 → 空欄
              変換できないもの（外貨・単位なしの小さい数字など）は要確認として残す
  従業員数    「1,234名（2026年3月時点）」→ 1234
  代表者名・  役職・部署・読み仮名・経歴・「様」などを外して名前のみにする
  担当者名    例:「代表取締役社長 山田 智司」→「山田 智司」
              外した役職は、役職列が空なら役職列に移す
              会社名・「採用担当」・「※※※」など名前でない値は空欄
  都道府県    住所の都道府県と違う場合は住所に合わせて修正
  郵便番号    郵便番号列があるときだけ空欄を補完・123-4567 に統一
              （列が無いリストには追加しない。追加したいときはルールをON）
              不正な番号は削除
  直せない値  資本金・従業員数・人名で自動変換できないものは削除
  TEL         ハイフン位置を市外局番に合わせて修正（025-836-7606 → 0258-36-7606、
              047-179-6113 → 04-7179-6113）。判定は番号の数字で行うので、
              ハイフン位置が間違っていても正しく市外局番を見る
              ハイフンの無いTEL（0312345678 等）はハイフンを追加、追加できない番号・桁数がおかしいTELは削除
              総務省「市外局番の一覧」と住所の市区町村を照合し、
              地域が違うものは削除（例: 住所が東京都なのに 06-xxxx）
              携帯・050・0120 等は対象外
              TELを消した行は行ごと除外行CSVへ（ルールでOFF可）

  修正後のファイル名の「_〇〇件」は実件数に自動で書き換わります。


■ 処理ルールのON/OFF（画面の「処理ルール」）

  自動修正・削除・除外はすべてチェックボックスで切り替えられます。
  消したくないものはチェックを外してから処理（処理後なら「このルールで再処理」）。
  設定はブラウザに記憶されます。結果画面とBacklog投稿文に「OFFにしたルール」が出ます。

    TELチェック   ハイフン追加・位置修正（追加できない番号は削除）/ ハイフンなし削除（既定OFF）/ 桁数違反 / 市外局番と住所の不一致 /
                  フリーダイヤル(0120/0800)除外 / 050除外 / 重複 / 空欄除去 / TELを消した行の除外
                  TELカラムは自動判定、画面で指定も可
    住所正規化    全角→半角（数字）/ 郵便番号除去（郵便番号列が空なら移す）/ 都道府県修正 / 郵便番号補完
                  住所カラムは自動判定、画面で指定も可
    名称・人名・数値  名称先頭の「=」/ 人名 / 資本金 / 従業員数 / 直せない値の削除
    行の除外      エリア外 / 期間外 / 〇〇店 / チェーン店 / 名称空欄 / 文字化け / 除外リスト
    各グループの「〜を有効にする」を外すと、そのグループはまとめてOFFになります。
    ルールの横に「このリスト: N件」と、ONにしたら消える件数が出ます。


■ 除外リスト（既存顧客・NGリストなど）

  画面左の「除外リスト」に、除外したい企業のCSV/Excelをドロップ
  （exclude フォルダに保存され、次回以降もチェックを入れるだけで使えます）。
  TEL・名称・住所の列は自動で見つけます。

  照合キー  TEL（初期値）            … 数字だけにして一致（削除前の元TELでも照合）
            名称+市区町村（任意）    … 法人格込みの名称と市区町村が同じ
            名称のみ（任意）         … 同名の別会社も消えるので注意
  一致した行は「_除外行.csv」に「除外リスト「〇〇」とTELが一致」のように理由付きで出ます。


■ 列の並び替え・出力する列

  結果画面の「列の並び・出力する列・充足率」で、☰をドラッグ or ↑↓で並べ替え。
  列名は枠の中を直接書き換えると出力時の列名が変わります。
  「削除」を押した列は出力しません（下の「削除した列」から「戻す」で復活）。
  「この並びで出力」で出力し直します。
  「今の並びをプリセット保存」で納品形式として保存でき（オーナーとも共有）、
  画面左「列の並び（新しく処理するとき）」で選ぶと次のファイルから自動で適用されます。


■ 期間系の列（掲載開始日（推定）・設立年月日・開業時期など）

  結果画面の「期間系の列の分布」に、列ごとの棒グラフが出ます。
    ・最も古い / 最も新しい / 中央 / 入力率
    ・3年以内なら月ごと、それ以上は年ごと（60年超は5年ごと）。両端1%の外れ値は端の棒にまとめる
    ・棒にマウスを乗せると件数
  リスト詳細に期間（「2024年1月～2026年12月」「2023年以降」「2020年以前」「直近3ヶ月」）があれば、
  その文に合う列（掲載→掲載開始日、設立→設立年月日 など）に自動で当てはめ、期間内を青・期間外を灰色で表示。
  画面で期間を入れると期間内・期間外・空欄の件数がすぐ出て、「期間外を除外して作り直す」で除外できます。
  和暦（令和6年・R6.3・平成30年）や 20240315 のような書き方も読めます。


■ チェックリスト

  チェックする項目   … リスト詳細の各行（媒体の該当件数、TEL充足、エリア外、
                       期間内/期間外/空欄の件数などを自動表示）とサンプル目視
  備考（自動処理）   … 件数、名称空欄、TEL重複・桁数・ハイフン、市外局番、郵便番号、
                       資本金、人名、業種充足率、都道府県と住所、文字化け
                       自動で直す・消すところまで済むので、画面下の「備考」に畳んで表示。
                       NGが残ったとき（ルールをOFFにした等）だけチェック項目に上がります
  自動判定: OK / NG / 確認（数値を見て判断）/ 目視（人が確認）


■ 出力（output フォルダ）

  結果画面の「納品用CSVをダウンロード」で落とせます。ファイル名は
    {処理した日付}【{課題キー}】{課題名}_{件数}件.csv
    例: 20260925【STREAMREQ-15281】関東　遺品整理_1230件.csv
  （課題に紐づかないファイルは元のファイル名の件数だけ書き換え）

  同じ名前で _除外行.csv（除外した行と理由）と _修正ログ.csv（どこを何から何に直したか）も出ます。
  元のファイルは input_done に保存されます（上書きしません）。

  「設定を変えて作り直す」… 左の処理ルールを変えたとき
  「列の変更を納品用CSVに反映」… 列の並び・列名・削除を変えたとき
  （どちらも元のファイルからもう一度作り直します。Backlogへの再取得はしません）


■ オーナーと共有する

  設定.txt の CHECKS_DIR を共有フォルダにすると、オーナーも自分のPCで
  このツールを起動して同じチェック状態を見て、チェックを付けられます。
  （例: CHECKS_DIR=\\Ra21\共有\DB\001_STREAM\...\目検チェック）
  Backlogへのコメント投稿でも共有できます。


■ データの更新

  郵便番号  ..\郵便番号補完ツール\data\utf_ken_all.csv（日本郵便）を差し替え
  市外局番  総務省ページ
            https://www.soumu.go.jp/main_sosiki/joho_tsusin/top/tel_number/shigai_list.html
            の最新PDFを data\shigai_kyokuban_soumu.pdf に置き直し、
            py build_shigai.py を実行（data\shigai_kyokuban.csv が作り直されます）


■ ファイル構成

  目検ツール.bat      起動
  app.py              画面・Backlog連携
  mokken_core.py      自動修正・チェックの本体
  areacode.py         市外局番と住所の照合
  backlog.py          Backlog API
  build_shigai.py     総務省PDF → 市外局番CSV
  設定.txt            BacklogのURL・APIキーの場所・チェック保存先など
  static/index.html   画面
  checks/             チェック状態（課題ごとのJSON）
  tasks.json          左端のタスクのタブ（完了・名前・メモ）

  Python 3.8 以上。追加ライブラリ不要（build_shigai.py のみ pypdf を使用）。
