# CSV 統合

`input` フォルダの CSV（列名・列の順番がすべて同じもの）を 1 つの CSV にまとめます。

## インストール

[ルートの README](../README.md) のとおり `checkTool` を取得すれば使えます。

## 設定

設定ファイルはありません。

- CSV は 2 件以上必要です。列名・順番が 1 つでも違うファイルがあると、統合せずに止まります
- 文字コードは UTF-8 / Shift_JIS を自動判定。出力は UTF-8（BOM 付き）

## 起動

1. `input` フォルダにまとめたい CSV を置く
2. `csv統合.bat` をダブルクリック
3. `output` フォルダに `{ファイル名の共通部分}_統合{件数}件.csv` が出る（元の CSV は `input_done` に移動）
