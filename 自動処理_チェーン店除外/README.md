# チェーン店・〇〇店 除外

チェーン店マスタと照合して、チェーン店の可能性が高い行と、店名が「店」で終わる行（支店表記）を除外します。
詳しいルールは `process_folder.py` の先頭の説明を見てください。

## インストール

[ルートの README](../README.md) のとおり `checkTool` を取得すれば使えます（Excel を読むため `openpyxl` が必要：`py -m pip install openpyxl`）。

## 設定

- チェーン店マスタ：社内共有サーバー（`\\Ra21\共有\DB\001_STREAM\05_スクレイピング\07_ 名寄せ元便利データ\チェーン店除外用店名マスタ.xlsx`）を自動で読む。繋がらないときは `chain_master_cache.xlsx`（自動更新）を使う
- 追加のチェーン名：チェーンだと確認できた店名（の一部）を `追加チェーン除外リスト.txt` に 1 行ずつ書く。次回の処理から、その文字列を含む行が除外されます

## 起動

1. `IN` フォルダに CSV を置く
2. `実行.bat` をダブルクリック
3. `OUT` フォルダに「除外後リスト」「削除した行」「要確認チェーン候補」と `_処理ログ.csv` が出る（元の CSV は `処理済み原本` に移動）
