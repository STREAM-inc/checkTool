===========================================================
 採用担当者 名寄せツール
===========================================================

リストCSVに、ハローワークの求人情報から採用担当者名を突合して埋めます。


■ 使い方

  1. input フォルダに、担当者名を埋めたいCSVを入れる（複数可）
  2. 採用担当者名寄せ.bat をダブルクリック
  3. output フォルダに結果が出力される
     処理が終わった入力ファイルは input_done へ移動します

  初回だけハローワークCSVの索引作成に1分ほどかかります。
  2回目以降はキャッシュを使うので数秒で終わります。
  ハローワークCSVを差し替えると自動で索引を作り直します。


■ 設定.txt

  ハローワークCSVの置き場所を書きます。CSVファイルでもフォルダでも可。
  複数行書くと全部まとめて索引化します（分割ファイルもそのまま置けます）。

  ハローワークCSVに必要な列： 名称 / TEL / 担当者
  あると精度が上がる列：      法人番号 / 住所 / 受付年月日 / 職種 / 取得URL


■ 入力CSVについて

  列名は自動で判定します。以下のような名前ならそのまま使えます。

    社名       … 名称 / 企業名 / 会社名 / 法人名 / 事業所名
    住所       … 本社住所 / 住所 / 所在地
    電話番号   … TEL / 電話番号 / 代表電話
    法人番号   … 法人番号
    出力先     … 採用担当者名 / 担当者名 / 採用担当者
    課係名     … 担当課係名 / 担当部署

  ・出力先の列が無いファイルには「採用担当者名」列を末尾に追加します。
  ・既に値が入っている「担当課係名」は上書きしません（空欄のみ補完）。
  ・文字コードは UTF-8 / Shift_JIS(CP932) を自動判定します。
  ・元ファイルは書き換えません。


■ 出力ファイル（output）

  〇〇_担当者名寄せ○件.csv
      元のCSVと同じ列構成のまま、担当者名を埋めたもの。これが成果物です。

  〇〇_名寄せ明細.csv
      埋めた1件ごとの根拠。どの方法で突合したか、社名・住所がどれだけ
      一致しているか、ハローワーク側の社名・住所・法人番号・職種・求人URL、
      同じ会社で見つかった担当者名の候補一覧が入っています。
      精度が気になるときはこれを見てください。

  〇〇_要確認候補.csv
      別法人の可能性があるため、あえて本体に反映しなかったもの。
      目視で問題なければ手で本体に移してください。

  〇〇_未取得一覧.csv
      埋まらなかった行と、その理由。


■ 突合ロジック（上から順に試して、最初に当たった方法を採用）

  ① 法人番号一致            … 最も確実
  ② 事業所TEL一致
  ③ 担当者欄の電話番号一致
  ④ 社名（法人格込み）+ 市区町村一致
  ⑤ 社名 + 都道府県のみ一致  … 要確認候補に回す（本体には入れない）

  ・入力側に法人番号があり、ハローワーク側の法人番号と食い違う求人は
    別会社と判断して候補から外します（同名・同市区町村の別法人対策）。
  ・②③で当たっても、社名も所在地も大きく違う場合は要確認候補に回します。

  同じ会社で複数の求人が見つかった場合の担当者名の選び方：
    1. カタカナ読みが付いているもの（＝実名の可能性が高い）を優先
    2. 同条件なら受付年月日が新しいものを優先
  「採用担当」のような総称は、実名が1件も無い場合だけ採用します。
  「契約社員」「〇応募の連絡について補足あり」のような、担当者名として
  成立しない値は除外します。


■ フォルダ構成

  採用担当者名寄せ.bat   起動用
  fill_recruiter.py      本体
  hw_index.py            ハローワークCSVの読み取り・索引
  設定.txt               ハローワークCSVの場所
  input/                 処理したいCSVを置く
  input_done/            処理済みの入力ファイル
  output/                結果
  cache/                 索引キャッシュ（約500MB・消しても再作成されます）


■ 動作環境

  Python 3.8 以上。追加ライブラリは不要です。
