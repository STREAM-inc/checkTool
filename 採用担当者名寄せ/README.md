# 採用担当者名寄せ

リスト CSV に、ハローワークの求人データから採用担当者名を突合して埋めます。
詳しい使い方・出力ファイルの説明は [README.txt](README.txt) を見てください。

## インストール

[ルートの README](../README.md) のとおり `checkTool` を取得すれば使えます。

## 設定

`checkTool` 直下の `setting.json` の `"採用担当者名寄せ"` → `"HW_CSV"` に、ハローワーク CSV の場所（ファイルかフォルダ）を並べる（`setting.example.json` をコピーして作る。書き方は [ルートの README](../README.md#設定)）。

```json
"採用担当者名寄せ": {
  "HW_CSV": ["C:/Users/.../ハローワーク_790897件.csv"]
}
```

`setting.json` が無いときは、このフォルダの `設定.txt`（1 行に 1 つ）を読みます。

- ハローワーク CSV に必要な列：`名称` / `TEL` / `担当者`（あれば `法人番号`・`住所`・`受付年月日`・`職種`・`取得URL` も使う）
- 初回だけ索引作成に 1 分ほどかかります（`cache` に保存。CSV を差し替えると自動で作り直し）

## 起動

1. `input` フォルダに、担当者名を埋めたい CSV を置く（複数可）
2. `採用担当者名寄せ.bat` をダブルクリック
3. `output` フォルダに結果が出る（元の CSV は `input_done` に移動）
