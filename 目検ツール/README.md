# 目検ツール（checkTool）

Backlog の課題の「リスト詳細」を 1 行ずつ確認しながら、納品リスト（CSV）を自動修正・チェックするためのローカル Web ツールです。
`目検ツール.bat` をダブルクリックすると、ブラウザで `http://localhost:8765` が開きます。

## できること

- **Backlog 連携**：課題番号を入れるとリスト詳細・エリア・添付ファイル・作業者の実行サマリを取得。添付 CSV をそのまま目検できる
- **自動修正**：TEL のハイフン追加・位置修正、市外局番と住所の照合、郵便番号の補完、住所の正規化、資本金・従業員数の表記統一、代表者名の整形 など
- **行の除外**：エリア外・期間外・チェーン店・TEL 重複・除外リスト（既存顧客 / NG リスト）との照合
- **チェックリスト**：担当・オーナーがそれぞれチェックを付けられ、結果を Backlog にコメント投稿できる
- **子課題**：子課題の一覧と詳細（本文）の表示、目検タスクの作成、「自分の担当にする」「処理済みにする」
- **タスクのタブ**：課題を開くと左端にタブが自動で増える。完了チェック・名前の変更・メモ。今日の課題一覧を貼り付けてまとめて追加・全部クリアも可
- **出力**：納品用 CSV（`{日付}【{課題キー}】{課題名}_{件数}件.csv`）、除外行 CSV（理由付き）、修正ログ CSV

画面の操作と自動修正ルールの詳しい説明は [README.txt](README.txt) を見てください。

## 必要なもの

- Windows 10 / 11
- Python 3.8 以上（`py` または `python` コマンド）。追加ライブラリ不要
  - Excel の除外リストを使うときだけ `openpyxl`、`build_shigai.py` を使うときだけ `pypdf`
- Backlog の API キー
- 郵便番号データ：隣の [`郵便番号補完ツール`](../郵便番号補完ツール/)（`fill_zip.py` と `data/utf_ken_all.csv`。このリポジトリに同梱）

フォルダの配置：

```
3-目検/                  ← リポジトリのルート
├─ APIキー.txt            ← Backlog の API キー（1 行・自分で置く）
├─ 郵便番号補完ツール/
│   ├─ fill_zip.py
│   └─ data/utf_ken_all.csv
└─ 目検ツール/            ← このフォルダ
```

## セットアップ

1. リポジトリ全体を `3-目検` という名前で取得する（[ルートの README](../README.md) も参照）

   ```bash
   git clone https://github.com/STREAM-inc/checkTool.git 3-目検
   ```

2. `3-目検` の直下の `APIキー.example.txt` を `APIキー.txt` にコピーし、中身を自分の Backlog の API キー 1 行だけにする
3. 必要なら `設定.example.txt` を `設定.txt` にコピーして書き換える（無くても初期値で動きます）

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| `BACKLOG_SPACE` | `https://streeeeeam.backlog.com` | Backlog スペースの URL |
| `APIKEY_FILE` | `..\APIキー.txt` | API キーを書いたファイル |
| `CHECKS_DIR` | `checks` | チェック状態の保存先。共有フォルダにするとオーナーと同じ状態を見られる |
| `TASKS_FILE` | `tasks.json` | 左端のタスクのタブの保存先（自分用） |
| `PORT` | `8765` | ブラウザで開くポート |
| `HW_CSV` | （空欄） | 市外局番チェックの参考にするハローワーク CSV |

## 起動

`目検ツール.bat` をダブルクリック → ブラウザが開きます。黒いウィンドウを閉じると終了します。

前に起動したままの目検ツールが残っていると、起動時に自動で終了させてから立ち上がります（古い画面が応答して新しい機能が動かない、を防ぐため）。

## 使い方（流れ）

1. 右上に自分の名前を入れる（チェックした人として記録されます）
2. 左の **＋ 手動で追加** → 課題番号（`15096` / `STREAMREQ-15096` / URL）を入れて **取得**
   - 今日の課題一覧を左の欄に貼り付けて **まとめて追加** すると、全部タブになります。タブをクリックするとその課題が開きます
3. 添付の **この添付で目検** を押す（または ＋ 手動で追加 のウィンドウに CSV をドロップ）
4. 自動修正された結果のチェックリストを上から確認して「担当」にチェック（オーナーは「オーナー」列）
5. 必要なら **Backlog にチェック結果を投稿**
6. **納品用 CSV をダウンロード**

## ファイル構成

| パス | 内容 |
| --- | --- |
| `目検ツール.bat` | 起動 |
| `app.py` | Web サーバー・画面の API・Backlog 連携・タスクのタブ |
| `mokken_core.py` | 自動修正・チェックの本体 |
| `areacode.py` | 市外局番と住所の照合 |
| `backlog.py` | Backlog API クライアント（標準ライブラリのみ） |
| `build_shigai.py` | 総務省の市外局番 PDF → `data/shigai_kyokuban.csv` |
| `static/index.html` | 画面 |
| `data/` | 総務省「市外局番の一覧」（PDF と CSV） |
| `設定.example.txt` | 設定のひな形 |
| `README.txt` | 利用者向けの詳しい説明 |

起動すると次のフォルダ・ファイルが作られます。**顧客データを含むので Git には入れません**（ルートの `.gitignore` で除外済み）。

| パス | 内容 |
| --- | --- |
| `input/` | 処理待ちの CSV を置くところ |
| `input_done/` | 処理した元ファイル |
| `output/` | 納品用 CSV・除外行・修正ログ |
| `exclude/` | 除外リスト |
| `checks/` | チェック状態（課題ごとの JSON） |
| `cache/` | 市外局番の判定キャッシュ |
| `tasks.json` | タスクのタブ |

- **郵便番号**：`..\郵便番号補完ツール\data\utf_ken_all.csv`（日本郵便）を差し替え
- **市外局番**：[総務省「市外局番の一覧」](https://www.soumu.go.jp/main_sosiki/joho_tsusin/top/tel_number/shigai_list.html) の最新 PDF を `data\shigai_kyokuban_soumu.pdf` に置き直して `py build_shigai.py`
