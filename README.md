# 3-目検（checkTool）

営業リスト（CSV）の目検・クレンジングに使うツールをまとめたフォルダです。
どれも Windows で `.bat` をダブルクリックして使います（Python 3.8 以上）。

| フォルダ | 何をするか | 起動 |
| --- | --- | --- |
| [目検ツール](目検ツール/) | Backlog の課題のリスト詳細を見ながら、納品 CSV を自動修正・チェックするブラウザ画面。チェックリスト・Backlog へのコメント投稿・子課題の操作・タスクのタブ | `目検ツール.bat` |
| [郵便番号補完ツール](郵便番号補完ツール/) | 住所から空欄の郵便番号を補完（日本郵便のデータを使用）。目検ツールもこのデータを使う | `郵便番号補完.bat` |
| [採用担当者名寄せ](採用担当者名寄せ/) | ハローワークの求人データと突合して、採用担当者名を埋める | `採用担当者名寄せ.bat` |
| [自動処理_チェーン店除外](自動処理_チェーン店除外/) | チェーン店マスタと照合してチェーン店・「〇〇店」の行を除外 | `実行.bat` |
| [統合](統合/) | `input` の CSV を 1 つにまとめる | `csv統合.bat` |

それぞれの詳しい使い方は各フォルダの README（`README.md` / `README.txt` / スクリプト先頭の説明）を見てください。

## セットアップ

1. 取得する

   ```bash
   git clone https://github.com/STREAM-inc/checkTool.git 3-目検
   ```

2. `APIキー.example.txt` を **`APIキー.txt`** という名前でコピーし、中身を自分の Backlog の API キー 1 行だけに書き換える（目検ツールで使用）
   - API キーは Backlog の「個人設定 → API」で発行できます
   - ファイルの中身はそのままキーとして使われるので、説明文やコメントは書かないでください
   - `APIキー.txt` は `.gitignore` で除外されているので、アップロードされません
3. 必要な人は各ツールの設定ファイルを作る（無くても初期値で動くものは不要）
   - `目検ツール/設定.example.txt` → `目検ツール/設定.txt`
   - `採用担当者名寄せ/設定.example.txt` → `採用担当者名寄せ/設定.txt`（ハローワーク CSV の場所）

```
3-目検/
├─ APIキー.example.txt       ← ひな形（これをコピー）
├─ APIキー.txt               ← 自分で作る（Git には入れない）
├─ 目検ツール/
├─ 郵便番号補完ツール/
│   └─ data/utf_ken_all.csv   ← 日本郵便の郵便番号データ（同梱）
├─ 採用担当者名寄せ/
├─ 自動処理_チェーン店除外/
└─ 統合/
```

## Git に入れないもの

顧客データ・個人の設定は `.gitignore` で除外しています。**API キーやリストを絶対にコミットしないでください。**

- `APIキー.txt`、各ツールの `設定.txt`、`tasks.json`
- 各ツールの作業フォルダ：`input/` `input_done/` `output/` `IN/` `OUT/` `処理済み原本/` `その他/` `checks/` `exclude/` `cache/`
- CSV / Excel / SQLite のファイル全部（公開データの `目検ツール/data/shigai_kyokuban.csv` と `郵便番号補完ツール/data/utf_ken_all.csv` だけ例外）

これらのフォルダはツールを起動すると自動で作られます。

## 変更をアップロードする

```bash
git add -A
git commit -m "変更内容"
git push
```

`git add -A` の前に `git status` で、リストや設定ファイルが入っていないか確認してください。
